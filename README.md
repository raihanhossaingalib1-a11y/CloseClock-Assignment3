# CloseClock - Personal Productivity Assistant

## Project Overview

CloseClock is a web-based personal productivity assistant designed to help users manage their daily tasks, track deadlines, and improve productivity.

The application allows users to create, update, delete, and complete tasks while providing a dashboard view of productivity performance.

---

## Features

### Task Management
- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Track task deadlines and priorities

### Dashboard
The dashboard displays:
- Total number of tasks
- Completed tasks
- Pending tasks
- Overdue tasks
- Productivity score

### Analytics
The system provides productivity insights based on task completion activities.

### Authentication
Users can securely log in and access their personal tasks.
